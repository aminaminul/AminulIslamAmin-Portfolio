# Screenshots

These PNGs were captured earlier in this project's development from a locally running instance.

They show the layout of an earlier content state (before the seeded test records were removed), so
treat them as design references rather than a picture of the current database, which ships empty by
design and is filled in from the admin panel.

| File | View |
| --- | --- |
| `public-home.png` | Public home page (narrow viewport) |
| `public-home-desktop.png` | Public home page (desktop) |
| `admin-dashboard.png` | Admin dashboard |

To capture current screenshots yourself, run the site, open `/` and `/Admin`, and take a screenshot
at 1440 px wide for desktop and 390 px wide for mobile.
